# Logistic Center

## Запуск (Node.js 20.6+)
1. `npm install`
2. Скопируйте `.env.example` в **`.env`** (с точкой!) и заполните `ADMIN_EMAIL` и SMTP.
3. Положите логотип в `public/logo.jpg`.
4. `npm start` → http://localhost:3000

Без SMTP коды входа печатаются в консоль сервера (для проверки на своём компьютере).

## Почта (SMTP)
Вход у клиентов работает с ЛЮБОЙ почтой (Gmail, Яндекс, Mail.ru…): код приходит им на ящик.
Сайту нужен один «исходящий» ящик — его данные в `SMTP_*`. Нужен **пароль приложения**, не обычный пароль:
- Яндекс: id.yandex.ru → Безопасность → Пароли приложений (включите доступ по IMAP/SMTP в настройках почты)
- Gmail: включите двухэтапную аутентификацию → myaccount.google.com/apppasswords
- Mail.ru: Настройки → Пароль и безопасность → Пароли для внешних приложений

## Админ
Войдите на сайте под `ADMIN_EMAIL` → иконка профиля → «Админ-панель» (`/admin`). Все остальные получают «Доступ запрещён» (проверка на сервере).
- Товары: название, категория, тип, цена, размеры, описание, несколько фото и видео (первое — обложка), скрыть с сайта.
- Заказы: заказы из корзины и ручные посылки, смена статуса (клиенту уходит письмо), редактирование.
- Контакты сайта: Telegram, WhatsApp, телефон, почта в подвале.

## Хостинг
Нужен Node.js и постоянный диск (VPS, Render/Railway с volume). Включите HTTPS и `NODE_ENV=production`.
Если перед сайтом nginx: `client_max_body_size 64m;` (иначе видео не загрузится).
Всё хранится в папке `data/` (пользователи, товары, заказы, загрузки) — делайте её резервную копию.
